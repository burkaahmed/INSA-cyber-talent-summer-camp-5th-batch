# Six-Week Curriculum

## Week 1 — Foundations

- Linux command line
- File permissions and processes
- Networking models
- DNS, HTTP, and TCP
- CTF conventions and flag formats

**Lab:** command-line treasure hunt

## Week 2 — Web Security

- HTTP requests and cookies
- Client/server trust boundaries
- Directory discovery
- Authentication and session flaws
- Secure coding practices

**Lab:** intentionally vulnerable local web application

## Week 3 — Cryptography

- Encoding vs encryption
- Substitution ciphers
- XOR and Base encodings
- Hashes and password storage
- Public-key concepts

**Lab:** decode and identify crypto weaknesses

## Week 4 — Digital Forensics

- File signatures
- Metadata and timestamps
- Log analysis
- Steganography
- Artifact correlation

**Lab:** investigate a miniature incident

## Week 5 — Reverse Engineering

- Binary structure
- Strings and disassembly
- Debugging workflow
- Scripted transformations

**Lab:** solve beginner binaries

## Week 6 — Competition

- Team roles
- Time-boxed solving
- Documentation discipline
- Final CTF
- Debrief and remediation review
