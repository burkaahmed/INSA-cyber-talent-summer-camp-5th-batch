# INSA Cyber Talent Summer Camp — 5th Batch

A hands-on, beginner-friendly Capture the Flag (CTF) training repository for the ASTU Excellence Cyber Division entrance camp.

> **Goal:** build practical cybersecurity skills through supervised, ethical, and isolated challenges.

## Learning Tracks

| Track | Skills | Folder |
|---|---|---|
| Linux & Networking | Shell, SSH, DNS, HTTP, packets | [`tracks/linux-networking`](tracks/linux-networking/) |
| Web Security | OWASP basics, auth, injection, hardening | [`tracks/web-security`](tracks/web-security/) |
| Cryptography | Classical and modern crypto concepts | [`tracks/cryptography`](tracks/cryptography/) |
| Forensics | Files, logs, memory, metadata | [`tracks/forensics`](tracks/forensics/) |
| Reverse Engineering | Assembly, binaries, debugging | [`tracks/reverse-engineering`](tracks/reverse-engineering/) |
| Social Engineering Awareness | Threat spotting and reporting | [`tracks/social-engineering`](tracks/social-engineering/) |

## Repository Structure

- `curriculum/` — weekly plans and lesson outlines
- `tracks/` — category-specific learning material and challenges
- `challenges/` — event manifests and flag registry templates
- `docs/` — rules, setup, reporting, and contribution guides
- `scripts/` — safe helpers for local training
- `assets/` — diagrams and downloadable resources

## Quick Start

1. Read [`docs/RULES.md`](docs/RULES.md).
2. Set up the environment using [`docs/SETUP.md`](docs/SETUP.md).
3. Use [`challenges/STARTER_CHALLENGES.md`](challenges/STARTER_CHALLENGES.md).
4. Submit reports with [`docs/SOLUTIONS_TEMPLATE.md`](docs/SOLUTIONS_TEMPLATE.md).

## Ethical Use

Only use these resources on systems you own or have permission to test. Never attack real users, public infrastructure, or competition systems outside the authorized scope.
