# Starter Challenges

These beginner exercises require no external services.

## 1. Hidden in Plain Sight — 50 points

Find a meaningful string in `assets/README.txt`.

## 2. Base Trail — 75 points

Decode `assets/encoded.txt`.

## 3. Log Detective — 100 points

Inspect `assets/example.log` and report:

1. The suspicious IP address.
2. The attempted username.
3. The most likely attack type.

## 4. Packet Primer — 125 points

A packet exercise can be created with `scripts/generate_packet_lab.py`.

## 5. Permissions Puzzle — 150 points

Review `tracks/linux-networking/PERMISSIONS_LAB.md` and identify the insecure permissions.

## 6. Web Header Mystery — 175 points

Start the local example in `tracks/web-security/README.md` and inspect HTTP headers and responses.
