# Contributing

## New Challenges

Every challenge must include:

- Clear objective
- Authorized target scope
- Difficulty and point value
- Setup instructions
- Solution for organizer use
- Cleanup instructions
- A short remediation lesson

## Pull Requests

1. Create a descriptive branch.
2. Keep changes focused.
3. Test commands before submitting.
4. Do not commit secrets or real flags.
5. Explain testing and expected behavior.

## Style

- Use Markdown headings.
- Use fenced code blocks with a language.
- Prefer examples that can run offline.
- Include warnings for potentially sensitive actions.
