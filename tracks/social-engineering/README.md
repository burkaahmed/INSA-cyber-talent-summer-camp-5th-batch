# Social Engineering Awareness Track

## Recognize

- Unusual urgency or pressure
- Requests to bypass procedures
- Unexpected attachments or links
- Identity claims that cannot be verified
- Requests for passwords or MFA codes

## Respond

1. Pause and verify independently.
2. Use a known contact channel.
3. Report the message through the authorized process.
4. Do not forward malicious content to unrelated people.
5. Preserve evidence and timestamps.

## Incident Report

- Sender details
- Delivery method
- Targeted request
- Indicators observed
- Users affected
- Actions taken
