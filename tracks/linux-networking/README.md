# Linux and Networking Track

Begin here: [`PERMISSIONS_LAB.md`](PERMISSIONS_LAB.md)

## Learning Objectives

- Navigate a Linux filesystem confidently.
- Understand permissions and processes.
- Trace network requests from client to server.
- Explain DNS, TCP, UDP, and HTTP at a practical level.

## Recommended Exercises

1. File and directory permissions
2. Sudo audit and least privilege
3. Local web service inspection
4. DNS enumeration in an authorized lab
5. Packet capture analysis
