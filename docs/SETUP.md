# Local Setup

## Recommended Tools

- Git
- Python 3.10+
- Visual Studio Code
- Kali Linux or Ubuntu virtual machine
- Docker and Docker Compose
- Wireshark
- Burp Suite Community Edition
- GDB

## Clone

```bash
git clone https://github.com/burkaahmed/INSA-cyber-talent-summer-camp-5th-batch.git
cd INSA-cyber-talent-summer-camp-5th-batch
```

## Python Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
```

## VS Code Extensions

- Python
- Docker
- Markdown All in One
- YAML

## Isolated Lab Checklist

- Disable shared clipboard/drag-and-drop where appropriate.
- Use a host-only or NAT network for labs.
- Take snapshots before risky experiments.
- Never reuse real passwords or production credentials.
